## Hosting at GitHub

The website is hosted on GitHub Pages. The provider is GitHub Inc., 88 Colin P. Kelly Jr. Street, San Francisco, CA 94107, USA. GitHub belongs to Microsoft.

When you open a page, your browser sends data to GitHub. That is your IP address, the time, the page you open, the page you come from, and details about your browser and operating system. GitHub needs this data to deliver the page and to protect it from attacks. GitHub stores it in server logs. I have no access to these logs.

The legal basis is my legitimate interest in a secure and fast website (Art. 6(1)(f) GDPR).

GitHub may transfer data to the USA. GitHub Inc. is certified under the EU-US Data Privacy Framework. This transfer is covered by the adequacy decision of the European Commission (Art. 45 GDPR). More on this: [GitHub Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement).

You have the right to access, rectification, erasure, restriction of processing, data portability and objection (Art. 15 to 21 GDPR). Just send me an email.

You can lodge a complaint with a supervisory authority. The one responsible for me is the Bavarian Data Protection Authority (Bayerisches Landesamt für Datenschutzaufsicht), Promenade 18, 91522 Ansbach, Germany.
