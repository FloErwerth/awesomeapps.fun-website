{%- comment -%} Updates as a block of cells, after the awards block on wodniack.dev. Cells left over at the end of the last row are hatched, so the block stays whole. With key_steps=true the block also shows each app's key milestones (the steps into a store, `key: true` in _data/apps.yml), newest first among the posts.     {%- for entry in entries limit: limit %} {%- assign shown = shown | plus: 1 %} {%- assign part = entry | split: "|" %} {%- if part[1] == "p" %} {%- assign i = part[2] | plus: 0 %} {%- assign post = include.posts[i] %}
  1. {{ post.date | date: t.date }} {{ post.title }} {%- if post.apps %} {%- for slug in post.apps -%} {%- assign tagged = site.data.apps | where: "slug", slug | first -%} {{ tagged.name }}{% unless forloop.last %}, {% endunless %} {%- endfor -%} {%- endif %}
    2. {%- else %} {%- assign app = site.data.apps | where: "slug", part[2] | first %} {%- assign i = part[3] | plus: 0 %} {%- assign m = app.milestones[i] %}
  2. {{ m.date | date: t.date }} {{ m.title[lang] }} {{ app.name }}
    3. {%- endif %} {%- endfor %} {%- if shown == 0 %}
  3. {{ t.updates_none }}
    4. {%- endif %} {%- assign rest = shown | modulo: 3 -%} {%- if rest > 0 %} {%- assign fill = 3 | minus: rest -%} {%- for k in (1..fill) %}
